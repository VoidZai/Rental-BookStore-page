# 📚 Rental Bookstore Page

An elegant and responsive online bookstore landing page built using **HTML**, **CSS**, and **JavaScript**. This project allows users to explore popular and recommended books with individual detail pages for each. The interface includes a light/dark mode toggle and a polished, modern design.

---

## 🚀 Features

- 🎨 Clean and responsive UI
- 🌙 Light/Dark mode toggle
- 📖 Book detail pages (`abcd1.html`, `abcd2.html`, `abcd3.html`)
- 🧭 Navigation buttons (`Back`, `Buy Now`)
- 📦 Semantic HTML structure
- ⚙️ Easy-to-maintain CSS
- 📱 Mobile-friendly layout
- 🔗 Footer with copyright

---

## 🔧 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Bootstrap (Optional)
